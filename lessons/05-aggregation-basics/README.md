# Lesson 05: Aggregation Basics

## Problem

The website needs a clean API response for a public book listing page.

Instead of returning full database documents, we want only the fields the frontend needs.

## Concepts

- Pipeline order
- `$match`
- `$sort`
- `$limit`
- `$project`

## Collections Used

- `books`

## Teaching Goal

Students should be able to read an aggregation pipeline from top to bottom and explain what each stage does to the documents.
