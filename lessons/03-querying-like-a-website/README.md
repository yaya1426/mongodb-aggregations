# Lesson 03: Querying Like A Website

## Problem

The public website needs common pages such as a book listing page, a genre page, and a featured books section.

Most of those pages can start with the Query API.

## Concepts

- Multiple filter conditions
- Matching array values
- Pagination with `skip()` and `limit()`
- Sorting by product fields

## Collections Used

- `books`

## Teaching Goal

Students should see that the Query API is great when the response shape is close to the original document shape.

At the end of this lesson, ask: what happens when we need calculated fields, grouped stats, author names, and review averages?
