# Lesson 06: Filter, Sort, And Project

## Problem

The listing page now has filters:

- Genre
- Minimum stock
- Maximum price

It also needs calculated labels for the frontend.

## Concepts

- More expressive `$match`
- `$and`
- `$project`
- `$cond`
- `$concat`

## Collections Used

- `books`

## Teaching Goal

Students should see how aggregation can both filter data and shape the exact response needed by a web page.
