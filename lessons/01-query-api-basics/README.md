# Lesson 01: Query API Basics

## Problem

The library website needs to list and inspect books from the database.

Before aggregation, MongoDB already gives us a Query API for common CRUD tasks: create, read, update, and delete documents.

## Concepts

- `find()`
- `findOne()`
- Query filters
- Projections
- Sorting and limiting

## Collections Used

- `books`

## Teaching Goal

Students should see that simple document lookup is easy with the Query API. This lesson sets the baseline for why aggregation is useful later.
