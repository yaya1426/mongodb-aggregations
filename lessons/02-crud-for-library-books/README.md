# Lesson 02: CRUD For Library Books

## Problem

The website admin needs to add, edit, and remove books.

This lesson shows how CRUD works with normal MongoDB commands before we introduce aggregation.

## Concepts

- `insertOne()`
- `updateOne()`
- `$set`
- `$inc`
- `deleteOne()`

## Collections Used

- `books`

## Teaching Goal

Students should understand that MongoDB documents can be created and changed directly. Aggregation is not a replacement for CRUD; it solves different read problems.
